## What is this?

A basic food delivery app built as a hybrid web application using PHP and MySQL. Covers the core ordering flow from restaurant discovery to checkout.

## 🍽️ Features

- 🏪 Restaurant / vendor listing
- 📋 Menu browsing with categories
- 🛒 Cart management
- 📦 Order placement and tracking
- 🔐 User authentication
- 🔧 Admin panel for restaurants

## 🚀 Setup

1. Import DB schema
2. Configure `config.php`
3. Deploy to PHP + MySQL host
